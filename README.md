# Study Mentor: Claude + WhatsApp setup guide

Turn Claude into a WhatsApp study mentor for your child or student, and run it from your phone.

## Two files, in this order

1. **[1-Start-Here.pdf](1-Start-Here.pdf)**: for you to read. It takes about 15 minutes: subscribe, install the Claude desktop app, open Code, and drop in file 2.
2. **[2-Give-This-To-Claude.pdf](2-Give-This-To-Claude.pdf)**: for Claude to read. Drag it into Claude's Code tab and type *"Read this setup guide and onboard me."* Claude walks you through the rest.

## Good to know

- Claude messages from **your own WhatsApp number** through WhatsApp Web. Keep it to 1 or 2 chats.
- It only **replies** when your student writes, plus a weekly progress report. It checks about every 2–3 hours when things are quiet.
- This is a basic setup. Do your own research to improve it.
